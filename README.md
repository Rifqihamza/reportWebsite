<div align="center">
  <h3>Chapter 2 : <i>The Purpose</i></h3>
</div>
As the problem grows larger, it overwhelmed us to manage all those reports from this area to another. On the other hand, We think that something like this can be solved by creating an interactive system that can be easily managed by teachers and staff.
<br />
<br />
I want to tell you about something. Something really big, and ambitious. It's the fact that, we're creating this website not just to make reports of findings around school easier to manage, but also to help teachers and staff spot what could be the root problem of a particular problem is. For example, if we know that a lot of hygiene problems occured around a particular date. We can create a deduction out of those data. Maybe there's an event that makes a lot of people not just a student from Mitra Industri Vocational HighSchool came to our school and eat, drink in the area of school and because of they don't get used to the rules of this school, they dumped their waste materials like plastic, food container, bottle of plastic not to their appropriate place. I know, maybe there's something more than just this event, maybe they already know about that and follow the rules obediently but, that's teachers and staff jobs to investigate this even further.
<br />
<br />
So, our main target is, <b>to create a software that can help teachers and staff managing the reports easily in a system where everything is integrated and connected</b>. Giving a digital experience of processing data, and analyze those data all in a platform where we can easily access with our phone or laptop. and if possible, we can actually use this website to find a core problem of some reports in a range of date, create some thoughts and conclusions that probably, we found a solutions to decrease the occurance of that particular type of reports.

<div align="center">
  <h3>Chapter 3 : <i>The Plan</i></h3>
</div>
<b>Data is important</b>. So, we planned to create a website that is used to collects data around the school. We want to make it automatically organize the data behind the scene so that we don't need to do the hard work. We have something that can really help us do the calculations. At the end, teachers and staff only need to see the reports, assign someone to clean the problem, and see the analytics to get insights from all of the report data. And if possible, find its core problem, then create an appropriate solution to solve it, so that we don't have to deal with those type of problem, ever again.
